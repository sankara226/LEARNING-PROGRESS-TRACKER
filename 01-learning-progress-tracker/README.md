# 01 — Learning Progress Tracker

**Type:** Interactive HTML artifact
**File:** `learning-progress-tracker.html`

## What it does

A visual 8-week × 5-class progress grid for tracking a Claude mentorship program (40 total classes). Open it in any browser — no server, no install needed.

- **Progress bar + percentage** — updates live as you mark classes done
- **Click-to-toggle grid** — click any cell to mark it complete or undo it
- **Log form** — type Week + Class number and hit "Log Completion"
- **Milestone banners** — appear at 50% and 100% completion
- **Reset button** — clears everything back to zero

## How to use

1. Open `learning-progress-tracker.html` in your browser (double-click it).
2. As you finish a class, either:
   - Click the cell directly in the grid, or
   - Type the week and class number in the form and click **Log Completion**.
3. The percentage, progress bar, and stats update instantly.

> **Note:** State is not persisted between page reloads. If you want to save progress, keep the tab open or bookmark the session.

## Why it's useful

Tracks structured learning programs where you have a fixed number of sessions per week. Gives you an immediate visual of momentum and remaining work — more motivating than a checklist.
